# مصروفي

تطبيق شخصي لتتبع المصروفات على الجوال. يلتقط العمليات تلقائياً من رسائل البنوك والمحافظ (الراجحي، الأهلي، برق) ومن Apple Pay عبر Wallet، يدمجها ويصنفها، ويحفظها على جوالك فقط. التكلفة صفر.

المواصفات الكاملة والقرارات والمخاطر في [SPEC.md](SPEC.md).

## كيف يعمل
```
الاختصارات ──POST /i──▶ Cloudflare Worker + KV (صندوق مؤقت)
التطبيق ◀──GET /p، POST /a── الصندوق
التطبيق ──▶ IndexedDB على الجوال (المخزن الدائم)
```

## النشر
1. **GitHub Pages**: ارفع المجلد كاملاً إلى مستودع عام، ثم Settings ← Pages ← Branch `main` والمجلد `/docs`.
2. **Cloudflare**: أنشئ Worker والصق محتوى `docs/worker.js`، وأضف السرّين `INGEST_KEY` و`PULL_KEY`، واربط مساحة KV باسم `INBOX`.
3. **الجوال**: افتح عنوان GitHub Pages في سفاري ← مشاركة ← إضافة إلى الشاشة الرئيسية، ثم اتبع «دليل الإعداد» داخل التطبيق (يولّد المفاتيح وينسخ ما تحتاجه).

## التطوير
لا توجد خطوة بناء ولا اعتماديات: جافاسكربت عادي (ES modules).

```
npm test            # كل الاختبارات (Node 20 أو أحدث)
npm run sync-worker # ينسخ worker/worker.js إلى docs/worker.js بعد أي تعديل عليه
```

اختبار يفشل إن اختلفت النسختان، فلا يصل للمستخدم صندوق غير مُختبَر.

## بنية المجلدات
- `docs/` التطبيق كله (يُنشر كما هو): `js/` المنطق والواجهة، `css/`، `icons/`، `sw.js` للعمل بلا اتصال، `worker.js` نسخة الصندوق التي يعرضها الدليل.
- `worker/worker.js` الصندوق (المرجع).
- `test/` الاختبارات، و`test/fixtures.js` فيه عينات الرسائل الحقيقية.
